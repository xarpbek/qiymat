# Qiymat 💎

> Premium personal finance manager — built as a Progressive Web App.

Qiymat (O'zbekcha: *qiymat*, "value / worth") is a beautiful, privacy-first finance manager that lives entirely in your browser. No backend, no tracking, no account required. Just open and track.

**Live:** https://xarpbek.github.io/qiymat
